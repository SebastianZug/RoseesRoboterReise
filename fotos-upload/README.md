# Fotos hochladen

Fotos von unterwegs hier hochladen (github.com → dieser Ordner → **Add file → Upload files**).
Die Action „Fotos verarbeiten“ übernimmt sie nach etwa 1–2 Minuten automatisch auf die Karte.

- Die Position kommt aus den GPS-Daten des Fotos. Fotos ohne GPS bleiben hier liegen und erscheinen nicht.
- Fotos, die mehr als 250 m von der Strecke entfernt aufgenommen wurden, werden gelöscht und nicht veröffentlicht.
- Auf der Webseite erscheinen nur verkleinerte Fassungen ohne Metadaten; der Upload wird danach aus dem Ordner entfernt.
- Das Ergebnis steht unter „Actions“ in der Zusammenfassung des jeweiligen Laufs.
